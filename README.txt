# Theoretical Mars Rover — Hackathon Website

## What is included
- `index.html` — the complete website
- `style.css` — visual design and responsive layout
- `script.js` — small scroll-reveal interactions
- `assets/mars-rover.glb` — your Blender 3D model
- `assets/rover-hero.png` — your hero render
- `assets/rover-side.png` — your side render
- `assets/rover-front.png` — your front render

## Run it
The simplest option is to open `index.html` in a browser. For the interactive 3D model, if your browser blocks local files, use a simple local server.

If you have VS Code:
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html`.
4. Choose "Open with Live Server".

## Publish it
A quick free option is GitHub Pages:
1. Create a GitHub repository.
2. Upload all files/folders in this project.
3. In the repository, go to Settings → Pages.
4. Choose "Deploy from a branch", select `main` and `/root`.
5. Save and wait for the site URL to appear.

## Technologies
HTML, CSS, JavaScript, Google Model Viewer, Blender 3D, GLB.
